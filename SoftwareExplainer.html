FIELD GUIDE / 01

รู้จักระบบMeet the system

สองส่วน ทำงานร่วมกัน เพื่อเก็บงาน label ของคุณTwo applications working together to keep your annotation work.

V▧

VisionLabel · หน้าจอทำงานVisionLabel · The workspace

โปรแกรมบน Windows สำหรับเปิดภาพ วาดและแก้กรอบสี่เหลี่ยม วาด polygon และกำหนดคลาสของภาพ Member ใช้หน้านี้ทำงาน ส่วน Admin ใช้จัดการโปรเจคและสมาชิกด้วยThe Windows desktop for viewing images, drawing and correcting rectangles, editing polygons and classifying images. Members label here; administrators also manage projects and people here.

FIELD GUIDE / 02

เริ่มใช้งานครั้งแรกFirst launch

เริ่มจาก source checkout บน Windows และ Python 3.12.10Start from a source checkout on Windows with Python 3.12.10.

เปิด PowerShell ในโฟลเดอร์ repository ใช้ Python 3.12.10 x64 และ pip ที่ติดมากับ Python ไม่ต้องลง uv ตรวจเวอร์ชันก่อน หากยังไม่มี .venv ให้สร้างเพียงครั้งแรก ถ้ามีแล้วให้ใช้ของเดิม การติดตั้งต้องเข้าถึง PyPI หรือ package index ของบริษัทได้Open PowerShell in the repository folder. Use Python 3.12.10 x64 and its bundled pip; uv is optional. Check the interpreter first. Create .venv only if it does not exist; otherwise reuse it. Installation needs access to PyPI or your company package index.

POWERSHELL
python --version
python -c "import struct; print(struct.calcsize('P') * 8)"
# Create only if .venv does not exist:
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

วิธีแนะนำ: เปิดทั้งสองส่วนพร้อมกันRecommended: launch both applications

POWERSHELL
.\.venv\Scripts\python.exe -m visionlabel.launcher --root D:\VisionLabelData

  1. ตั้งรหัสผ่าน AdminSet the admin password

    ครั้งแรก terminal จะให้ตั้งรหัสผ่านอย่างน้อย 12 ตัวอักษรและยืนยันอีกครั้ง ใช้ชื่อผู้ใช้ admin ไม่มีรหัสผ่านเริ่มต้นให้On first launch, the terminal asks you to create and confirm a password of at least 12 characters. The username is admin; there is no default password.

  2. เข้า workspaceEnter the workspace

    ล็อกอินด้วยบัญชีที่สร้างไว้ เมื่อปิด desktop ตัว launcher จะหยุด service ที่มันเปิดให้ด้วยSign in with the account you created. Closing the desktop also stops the service owned by the launcher.

  3. ใช้ DataRoot เดียวกันทุกคำสั่งUse the same DataRoot throughout

    ตัวอย่างคู่มือนี้ใช้ D:\VisionLabelData หากไม่ระบุ --root ค่าเริ่มต้นคือ %LOCALAPPDATA%\DataTrackingThis guide uses D:\VisionLabelData. Without --root, the default is %LOCALAPPDATA%\DataTracking.

เปิด Server และ Client แยก terminalRun server and client in separate terminals

ใช้แทน launcher เมื่ออยากควบคุม service แยกต่างหาก รัน init เฉพาะตอนตั้งค่า Admin ให้ data directory ใหม่Use this instead of the launcher when you want independent service control. Run init only when creating the administrator for a new data directory.

POWERSHELL
.\.venv\Scripts\python.exe -m visionlabel.cli init --root D:\VisionLabelData
.\.venv\Scripts\python.exe -m visionlabel.cli serve --root D:\VisionLabelData

เปิด PowerShell อีกหน้าต่างแล้วรัน Client บนเครื่องเดียวกันOpen another PowerShell window and run the client on the same machine.

POWERSHELL
.\.venv\Scripts\python.exe -m visionlabel.desktop --server http://127.0.0.1:8765
ถ้า service เปิดอยู่แล้ว อย่าเปิด launcher ซ้ำกับ DataRoot เดิม ให้เปิดเฉพาะ desktop ตามคำสั่งด้านบนIf the service is already running, open only the desktop with the command above instead of launching a second service for the same DataRoot.
FIELD GUIDE / 03

ฝั่ง Server / AdminServer / Admin

เตรียมข้อมูล สร้างโปรเจค และกำหนดสิทธิ์ให้ทีมPrepare data, create projects and grant access.

ADMIN PLAYBOOK

  1. สร้างโปรเจคCreate a project

    เลือก New project ใส่ชื่อ, slug เช่น spring-inspection, task type และชื่อคลาสคั่นด้วย comma ใช้ detection สำหรับ bbox, segmentation สำหรับ polygon หรือ classification สำหรับหนึ่งคลาสต่อภาพChoose New project. Enter a name, a slug such as spring-inspection, a task type and comma-separated class names. Use detection for boxes, segmentation for polygons, or classification for one label per image.

  2. เตรียมภาพใน inboxPrepare the inbox

    คัดลอก PNG/JPG/JPEG/BMP ลง D:\VisionLabelData\inbox เลือกโปรเจคปลายทาง แล้วกด Import inbox ตรวจ Last import report ว่าไฟล์ใดสำเร็จ ซ้ำ หรือไม่ผ่านCopy PNG/JPG/JPEG/BMP images into D:\VisionLabelData\inbox. Select the destination project, choose Import inbox, and inspect Last import report for imported, duplicate and invalid files.

  3. สร้างบัญชีให้คนทำงานCreate the account

    ไปที่ Team & users → Accounts (administrator) → New account form ใส่ username, display name และรหัสผ่านอย่างน้อย 12 ตัวอักษร แล้วกด Create accountOpen Team & users → Accounts (administrator) → New account form. Enter a username, display name and password of at least 12 characters, then choose Create account.

  4. เพิ่มบัญชีเข้าโปรเจคAdd the account to the project

    ใน Project members เลือกบัญชีจาก User, เลือก annotator แล้วกด Add / update role ต้องทำขั้นตอนนี้ด้วย เพราะมีบัญชีอย่างเดียวจะยังไม่เห็นโปรเจคIn Project members, select the account under User, choose annotator and click Add / update role. An account alone does not grant access to a project.

Role changes revoke leases in that project. If membership edits conflict, choose Refresh before trying again.

FIELD GUIDE / 04

ฝั่ง Client / MemberClient / Member

เริ่มจากบัญชีและสิทธิ์โปรเจคที่ Admin เตรียมไว้Begin with an account and project access from your administrator.

MEMBER PLAYBOOK

  1. เข้าสู่ระบบSign in

    เปิด Connection ใช้ username/password ที่ Admin ให้ และ URL http://127.0.0.1:8765 บนเครื่องที่เปิด service อยู่Open Connection and sign in with the administrator-provided credentials at http://127.0.0.1:8765 on the machine running the service.

  2. เลือกโปรเจคและภาพChoose a project and image

    เลือกโปรเจคจากรายการ ใช้ search filename และ status filter เพื่อหาภาพ เมื่อเปิดภาพเพื่อแก้ ระบบจะจองสิทธิ์แก้ภาพให้ชั่วคราวChoose a project. Use filename search and the status filter to find an image. Opening an image for editing acquires a temporary editing lease.

  3. ทำ annotation และบันทึกAnnotate and save

    วาดหรือแก้กรอบ เลือกคลาส แล้วใช้ Ctrl+S หรือ autosave รอให้สถานะบันทึกได้รับการยืนยันจาก server ก่อนถือว่างานถูกเก็บแล้วDraw or correct shapes and select a class. Use Ctrl+S or autosave. Wait for server confirmation before treating your work as saved.

  4. ตรวจงานด้วยการเปิดกลับมาCheck your saved work

    ไปภาพถัดไปแล้วกลับมาดูอีกครั้ง กรอบและคลาสควรเหมือนเดิม หากระบบแจ้งว่าภาพถูกจอง ให้รอผู้ใช้งานเดิมปล่อยภาพNavigate away and back to confirm the shapes and classes. If the image is already claimed, wait for the current editor to release it.

ไม่เห็นโปรเจค?Project missing?

ให้ Admin ตรวจ Project members และ role ของบัญชีคุณ การสร้างบัญชีกับการให้สิทธิ์เข้าโปรเจคเป็นสองขั้นตอนAsk the administrator to check Project members and your role. Account creation and project membership are separate steps.

จะใช้จากอีกเครื่อง?Using a second PC?

การเชื่อมต่อ remote ยังไม่รองรับใน build นี้ ตอนนี้ใช้บัญชี Member ทดสอบบนเครื่องเดียวกับ service ได้ แผน LAN/HTTPS อยู่ในงานที่ยังต้องทำต่อRemote connections are not supported by this build. Member accounts can be exercised on the service machine today; LAN/HTTPS remains planned work.

FIELD GUIDE / 06

นำกรอบจากโมเดลมาแก้ต่อBring your model’s boxes back

Label ชุดเล็ก → train ภายนอก → infer ภายนอก → import → แก้ไขLabel a seed set → train externally → infer externally → import → correct.

Import YOLO ใช้งานได้แล้ว ส่วนการ train/inference ทำด้วยเครื่องมือภายนอก และ production dataset export จากโปรแกรมนี้ยังไม่พร้อม ขั้นตอนออกข้อมูลไปเทรนจึงต้องใช้วิธีภายนอกที่คุณมีอยู่YOLO import is available. Training and inference use external tools, and production dataset export from this application is still pending. Getting seed data into training currently requires your existing external workflow.

วางไฟล์คู่กันKeep each pair together

D:\VisionLabelData\inbox\
└─ batch_01\
   ├─ spring_img.bmp
   └─ spring_img.txt

จับคู่ด้วยชื่อเดียวกันในโฟลเดอร์เดียวกัน รองรับ subfolder หากมี spring_img.png กับ spring_img.bmp อยู่ด้วยกัน จะถือว่ากำกวมและปฏิเสธPairs must have the same stem in the same folder. Subfolders work. Having both spring_img.png and spring_img.bmp together is ambiguous and rejected.

Predictions start at revision 1 with IN_PROGRESS status; your correction creates the next revision.

ไม่มี .txt = ยังไม่ได้ label · .txt ว่าง = ยังไม่ได้ label เช่นกัน เว้นแต่ติ๊ก Treat empty .txt files as verified empty ไว้อย่างชัดเจน ภาพที่มี annotation revision อยู่แล้วจะไม่ถูกเขียนทับ และ prediction จะไม่ถูกอนุมัติอัตโนมัติMissing .txt = unlabeled. Empty .txt is also unlabeled unless Treat empty .txt files as verified empty is explicitly selected. Existing annotation revisions are never overwritten, and predictions are never automatically approved.

Preview ไม่ได้ล็อกไฟล์ไว้ Import จะอ่านใหม่ หากเกิด conflict หลังนำภาพเข้าแล้ว ภาพอาจคงอยู่โดยยังไม่มีกรอบ ให้ตรวจ image_retained และ label_state ในรายงานก่อนแก้สาเหตุแล้วลองใหม่ TXT ที่ไม่มีภาพคู่กันจะไม่ถูกเลือกจากการ scan ภาพPreview does not reserve files; import reads them again. A later conflict can leave an imported image without predictions. Check image_retained and label_state, resolve the cause and retry. TXT files without a paired image are not selected by the image scan.

It does not watch the folder automatically. Selecting another project and importing again can add those same images to that project.

It works offline, does not connect to the service and does not read your datasets. Screenshots use synthetic data.

บันทึก สำรอง และกู้คืนSave, back up, recover

แยกงานที่บันทึกกับ server แล้ว ออกจาก draft ในเครื่องDistinguish confirmed server saves from local drafts.

Member: เมื่อหลุดหรือ save conflictMember: disconnects and save conflicts

draft และ cache อยู่ใต้ %LOCALAPPDATA%\VisionLabel โดยป้องกันด้วย Windows DPAPI หาก server ใช้ไม่ได้ยังแก้ในเครื่องต่อได้ แต่ต้องกลับมาเชื่อมต่อก่อน save กลาง ใช้ Reload / reconnect เพื่อเปรียบเทียบกับ revision ล่าสุดDrafts and cache live under %LOCALAPPDATA%\VisionLabel, protected by Windows DPAPI. During a disconnect you can edit locally, but shared saves require reconnection. Use Reload / reconnect to compare against the latest server revision.

เลือก restore draft เมื่อระบบยืนยันว่าฐาน revision ตรงกัน หากเก่าแล้วต้องเทียบและนำการแก้กลับมาเอง ไม่มี force overwriteRestore a draft when its base revision matches. A stale draft requires comparison and manual reapplication; there is no force overwrite.

Admin: สำรองหลังหยุด serviceAdmin: back up after stopping the service

ปิด launcher/desktop และรอ service หยุดก่อน backup ใช้ปลายทางใหม่ทุกครั้ง ระบบตรวจฐานข้อมูลและ hash ของไฟล์ ก่อนเผยแพร่ชุด backup ที่สมบูรณ์Close the launcher/desktop and wait for the service to stop. Always choose a new backup destination. The service verifies the database and file hashes before publishing a complete backup set.

POWERSHELL
.\.venv\Scripts\python.exe -m visionlabel.cli backup --root D:\VisionLabelData --destination E:\VisionLabelBackups\run-001
.\.venv\Scripts\python.exe -m visionlabel.cli verify-backup --backup-set E:\VisionLabelBackups\run-001
กู้คืนไปยังโฟลเดอร์ใหม่Restore into a new folder
POWERSHELL

.\.venv\Scripts\python.exe -m visionlabel.launcher --root D:\VisionLabelRestored

Restore จะยกเลิก session/lease เดิม จึงต้องล็อกอินใหม่ ตรวจภาพและ annotation ก่อนใช้งานต่อ อย่า restore ทับโฟลเดอร์ liveRestore invalidates old sessions/leases, so sign in again and inspect images and annotations before continuing. Never restore over the live data folder.

Backup ครอบคลุมฐานข้อมูล ภาพใน managed, schema และประวัติ annotation แต่ไม่รวม inbox, cache และ draft ในเครื่อง Client ชุด backup มีข้อมูลบัญชีและ password hashes จึงต้องเก็บในพื้นที่จำกัดสิทธิ์Backups cover the database, managed images, schemas and annotation history. They exclude inbox files and client cache/drafts. Backups contain account data and password hashes; restrict access to their storage.

คำถามที่พบบ่อยCommon questions

คำตอบสั้น ๆ สำหรับจังหวะที่ติดขัดA quick reference for the moments you get stuck.

เปิดไม่ได้ แจ้ง data directory ถูกใช้งานอยู่The data directory is already in use

อาจมี service หรือ launcher เปิดอยู่แล้วสำหรับ DataRoot เดียวกัน ใช้ desktop เชื่อมต่อ instance เดิม หรือปิด instance เดิมก่อนเปิดใหม่A service or launcher may already own that DataRoot. Connect the desktop to that instance, or close the existing instance before restarting.

Import ซ้ำแล้วกรอบที่แก้จะหายไหมWill another import erase my corrections?

YOLO import จะปฏิเสธภาพที่มี annotation revision แล้ว ภาพเดียวกันในโปรเจคเดียวกันตรวจซ้ำจาก SHA-256 ของ bytes ภาพ ไม่ได้ดูแค่ชื่อไฟล์YOLO import rejects images that already have an annotation revision. Image duplicates within a project are detected by their byte SHA-256, not only their filenames.

โมเดลจับไม่เจอทุกภาพ ให้ติ๊ก verified empty เลยไหมShould all empty model outputs be verified empty?

ไม่ควรสรุปจากผลโมเดลอย่างเดียว ภาพที่ไม่มี prediction อาจเป็น false negative ให้คนตรวจภาพก่อนยืนยันว่าไม่มีวัตถุจริง ๆAn empty prediction can be a false negative. Have a person inspect the image before confirming that it truly contains no objects.

Preview ผ่าน แต่ import ไม่สำเร็จPreview passed but import failed

ระหว่างสองขั้นตอน ไฟล์ สิทธิ์ schema หรือ lease อาจเปลี่ยนได้ ตรวจ Last import report และแก้สาเหตุก่อน retry งานที่มีอยู่จะไม่ถูก overwriteFiles, permissions, schema or leases may change between the two operations. Inspect Last import report, resolve the cause and retry. Existing annotations are not overwritten.
